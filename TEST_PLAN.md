# Phase 1 manual test plan

- [ ] Dashboard renders at 1440px, 768px, and 375px widths without horizontal overflow.
- [ ] Empty answer cannot be saved; a valid answer can be saved.
- [ ] Answer length is limited to 500 characters.
- [ ] Saved answer becomes read-only in that demo tab.
- [ ] Partner demo tab can save a separate answer.
- [ ] Reveal remains locked until both answers exist.
- [ ] Reveal shows both answers after both are saved.
- [ ] Room dialog opens, edits names/code, and closes.
- [ ] Reset clears saved answers and restores sample values.
- [ ] Refresh retains demo state when browser storage is available.
- [ ] Keyboard focus is visible and dialog has an accessible label.
- [ ] Storage failure displays a helpful status message.

Automated tests and real backend security tests are planned for Phase 2; do not claim them as completed yet.
